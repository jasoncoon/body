# Body

Completely client-side viewer for body-composition data from a <a href="https://www.weightgurus.com" target="_blank" rel="noreferrer noopener">Weight Gurus</a> scale.

https://jasoncoon.github.io/body

Data must be exported via the app to CSV format:

```
Weight (lb), Body Fat, Muscle Mass, Water, BMI, Bone Mass, Date/Time
185.0, 20.6%, 36.7%, 61.5%, 25.1, 0%, Feb 07 2025 07:48:48 AM
```
